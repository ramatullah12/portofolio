## Tech Stack
- **React 19** + **TypeScript**
- **Tailwind CSS v4** (`@tailwindcss/vite`)
- **Framer Motion** (animasi transisi & micro-interactions)
- **React Icons** & **React Router v7**
- **Vite 8**

## Cara Menjalankan Proyek

```bash
cd portfolio
npm install
npm run dev
```

Untuk membuat *production build*:

```bash
npm run build
npm run preview
```
